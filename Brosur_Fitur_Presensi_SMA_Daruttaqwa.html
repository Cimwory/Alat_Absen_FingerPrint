SMA DARUTTAQWA

Sistem Presensi Digital & Alat Absen IoT Berbasis Google Sheets

Panduan Resmi Klien
Edisi Pembaruan: September 2026

Solusi Absensi Modern, Bebas Ribet & Akurat

Generasi baru sistem presensi yang menggabungkan Alat Absen IoT (Sidik Jari & RFID) dengan Dashboard Web Interaktif. Pendaftaran guru & kartu kini sangat mudah langsung lewat web tanpa perlu akses IP alat, sistem bebas bentrok ID, serta rekapitulasi data otomatis lengkap dengan persentase kehadiran.

Cara Kerja Sistem yang Sangat Sederhana (3 Detik Beres)
1
Guru Datang & Tap
Guru menempelkan jari / kartu di mesin absen sekolah.
2
Mesin Verifikasi
Layar menyapa nama guru & buzzer berbunyi "bip" tanda sukses.
3
Langsung Masuk Cloud
Data jam detik tersimpan otomatis di Google Spreadsheet.
4
Terlihat di HP / Web
Kepala Sekolah & Guru bisa langsung melihat laporannya.
Fitur-Fitur Baru pada Mesin Alat Absen (Hardware IoT)
Dua Sensor Pengenal (Sidik Jari & Kartu)
Guru bebas memilih cara absen: cukup tempelkan sidik jari atau gunakan kartu (RFID / e-KTP). Sensor optik R307 cepat membaca meski jari agak berkeringat.
Manfaat: Fleksibel, jika jari basah/terluka bisa pakai kartu.
Pencegah Salah Pulang (Tap Konfirmasi)
Mencegah guru yang baru datang tidak sengaja terabsen pulang. Tap pertama = Masuk. Untuk absen pulang, mesin meminta tap 2 kali sebagai konfirmasi.
Manfaat: Jam kepulangan 100% akurat, tidak ada salah pencet.
Daftar Guru Praktis via Web (Tanpa Buka IP Alat)
Dulu di sistem lama, mendaftarkan guru harus membuka alamat IP alat (192.168.x.x) yang rumit dan wajib satu WiFi. Sekarang cukup dari Web Dashboard di HP/Laptop, alat otomatis tersinkron.
Manfaat: Pendaftaran cepat kapan pun tanpa perlu paham teknis IP.
Sistem Bebas Bentrok ID & Multi-Mesin
Pada sistem lama, nomor ID kartu/jari rawan bentrok atau menimpa guru lain. Sistem baru dilengkapi alokasi ID unik otomatis, aman digunakan pada Mesin A maupun Mesin B.
Manfaat: 100% aman, tidak ada data guru yang tertukar atau hilang.

Keamanan Memori Alat Absen

Mesin absen ini menggunakan modul memori terenkripsi. Meskipun listrik padam atau koneksi WiFi terputus sesaat, data sidik jari guru yang sudah terdaftar tetap aman tersimpan di dalam mesin tanpa perlu registrasi ulang.

DASHBOARD WEB PRESENSI

Fitur Pemantauan Real-Time, Laporan Bulanan, & Pengelolaan Guru

Tampilan Web & Mobile
Edisi Pembaruan: September 2026
Fitur-Fitur Baru pada Dashboard Web (Aplikasi Pantau)
Pemantauan Check In & Check Out Real-Time
Dashboard otomatis menampilkan jam masuk (Check In) dan kepulangan (Check Out) otentik dari ketukan sensor sidik jari & kartu RFID. Live feed mencatat kehadiran detik demi detik secara transparan.
Manfaat: Data kehadiran 100% riil dari mesin tanpa rekayasa.
Bebas Custom Nama Guru, Gelar, & Jabatan
Admin dan guru dapat menyesuaikan nama lengkap, gelar akademik, NIP/ID, peran (Pengajar vs Tata Usaha), dan status penugasan (Tetap / Honorer) secara mandiri lewat dashboard web.
Manfaat: Data guru selalu rapi dan fleksibel disesuaikan kapan saja.
Mode Rekapitulasi Mandiri (Privasi Terjaga)
Ketika guru login dengan akunnya (seperti Bu Miftahul Jannah), sistem otomatis memproteksi privasi dengan hanya menampilkan jadwal pribadi dan riwayat presensi miliknya sendiri tanpa terlihat guru lain.
Manfaat: Privasi guru terlindungi, aman dan nyaman digunakan.
Ekspor Excel 1-Klik & Akses Vercel Online
Unduh rekap kehadiran bulanan ke file Microsoft Excel (.xls) atau CSV dalam 1 kali klik. Website aktif online 24 jam di dashboardabsensmadta.vercel.app dengan navigasi sentuh ramah smartphone.
Manfaat: Laporan siap cetak untuk yayasan, akses fleksibel lewat HP.
Perbandingan Nyata: Sistem Presensi Lama vs Sistem IoT Baru
Kriteria Sistem Lama Sistem Baru SMA Daruttaqwa (IoT)
Pendaftaran Guru Ribet Wajib akses alamat IP alat (192.168.x.x) dan harus satu jaringan WiFi alat. Sangat Mudah Cukup buka Web Dashboard dari HP/Laptop di mana saja, alat otomatis sinkron.
Keamanan ID Rawan Bentrok ID kartu / sidik jari bisa bertabrakan atau saling menimpa data guru lain. Bebas Bentrok Sistem ID unik terproteksi otomatis; data presensi dijamin tidak akan tertukar.
Profil & Nama Guru Kaku Sulit custom nama guru, gelar, atau status penugasan pengajar. Bebas Custom Bisa atur nama lengkap guru, gelar, NIP, status guru tetap/honorer di web.
Pengolahan Data Data Mentah Hanya deretan log baris di sheet yang membingungkan orang awam. Otomatis & Jelas Dashboard langsung merangkum guru hadir, jam masuk, jam pulang, dan status alat IoT.
Rekap & Laporan Manual Admin harus menghitung rumus spreadsheet sendiri untuk laporan rapat. 1-Klik Ekspor Sekali klik langsung jadi file Excel (.XLS) rapi siap dicetak untuk yayasan.

Hak Akses Bertingkat untuk Menjaga Privasi & Kenyamanan:

1. Guru Pengajar: Mode Mandiri — hanya dapat melihat jadwal mengajar pribadi dan riwayat presensi miliknya sendiri.
2. Administrator Sistem / Kepala Sekolah: Akses Menyeluruh — memantau seluruh guru, jadwal pelajaran, ekspor laporan Excel, dan status alat presensi IoT.
3. Akses Publik Online: Dapat dibuka kapan saja melalui domain resmi: https://dashboardabsensmadta.vercel.app
